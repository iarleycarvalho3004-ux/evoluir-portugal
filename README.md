# EVOLUIR PORTUGAL

Aplicativo web pessoal (PWA) de acompanhamento de treino, nutrição e evolução corporal.
Armazenamento 100% local no aparelho. Estado atual: **Etapa 2B** (estrutura visual).

Comandos (para uso futuro em computador; o fluxo normal roda na nuvem):
`npm install`, `npm run dev`, `npm run typecheck`, `npm test`, `npm run build`.

Decisões e estado do projeto: `docs/DECISIONS.md`.
